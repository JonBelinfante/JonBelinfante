# Jon Belinfante

My Public Repos are for teaching aids and tools that add value to modern software engineering. More to follow.

**New: [backbone-resilience](https://github.com/JonBelinfante/backbone-resilience)** is a teaching aid for high availability and recovery in PostgreSQL. It has runnable tests with negative controls, measured recovery point and recovery time figures, a learning path, and a command reference for monitoring and control.

The repository is archived until I have time to build the next features. It is readonly. You are welcome to read, clone and fork it.
